OTP Verification API

Lightweight, fast & reliable one-time password verification powered by Gmail.

https://shaurya-mail-otp-veri.vercel.app

Quick Start

Two simple endpoints. No authentication required for testing.

cURL · Send OTP 
curl "https://shaurya-mail-otp-veri.vercel.app/api/otp?mail=user@example.com"
cURL · Verify OTP 
curl "https://shaurya-mail-otp-veri.vercel.app/api/otp?mail=user@example.com&otp=482913"

Send OTP

GET /api/otp?mail={email}

Generates a 6-digit OTP, stores it for 5 minutes, and delivers it to the provided email address.

Parameter Type Description
mail required string Recipient email address
Success · 200
{
  "success": true,
  "message": "OTP sent successfully"
}
Error · 400
{
  "success": false,
  "error": "mail parameter required"
}

Verify OTP

GET /api/otp?mail={email}&otp={code}

Validates the OTP against the stored value. OTPs are single-use and expire after 5 minutes.

Parameter Type Description
mail required string Email used during send
otp required string 6-digit OTP code
Success · 200
{
  "success": true,
  "message": "OTP verified successfully"
}
Error · 400
{
  "success": false,
  "error": "Invalid OTP"
}
